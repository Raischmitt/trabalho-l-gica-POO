# Sistema de Gestão de Frota (POO + Streamlit)

Aplicação desenvolvida em **Python** aplicando os pilares da **Programação Orientada a Objetos (POO)**, persistência em **JSON** e interface web interativa com **Streamlit** para gerenciamento de uma frota mista (`Carro`, `Caminhao` e `Moto`).

## Contexto e Objetivo do Sistema

O sistema simula a operação de uma locadora/gestora de frota que precisa cadastrar veículos, controlar disponibilidade e quilometragem, simular valores de locação com regras distintas por categoria e manter os dados salvos entre execuções sem depender de banco de dados externo.
